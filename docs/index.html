System overview

The browser talks to nginx on hp6033a at 192.168.1.100. nginx proxies requests to Gunicorn over /run/hp6033a/gunicorn.sock. The Flask application uses PyVISA with the Python backend to reach the supply through USB-to-GPIB. A separate USB serial probe reports the interface firmware and response time.

Modern dashboard
Live readings, GPIB interface status, history, presets and remote programming controls.
Classic front panel
Instrument-style readback and staged voltage/current adjustment. Apply submits the staged value through the same server checks as the Modern dashboard.

Operation

In Live Read Only, the controller queries the supply for setpoints, voltage, current and output state. The status API currently reports regulation as unknown. Use the GPIB connection indicator before interpreting a reading. When GPIB fails, the API reports output as unknown and measured values default to zero.

  1. To program the supply, confirm its output is off and the existing setpoints are within the controller limits. Authorize remote programming from either dashboard with the control login.
  2. With output confirmed off, apply a voltage from 0 to 20 V and a current limit from 0 to 30 A. A selected preset turns green immediately on either dashboard. Press Apply to send the staged settings and see the instrument readback. Reset discards staged changes and restores the highlight to the programmed values. The supply is autoranging. The maximum voltage and maximum current are separate setpoint limits. Available simultaneous output depends on the instrument's power envelope.
  3. Before enabling output, verify the load and applied setpoints. The server checks that output is off and requires a current setpoint of at least 0.001 A for output-on.
  4. Use Output OFF to request shutdown and check the confirmation. The controller keeps the current remote programming authorization after confirming output is off. If it cannot verify shutdown, it clears authorization.

Disabling remote programming and restarting the web service both clear permission to program the supply. Neither action issues a hardware output-off command. If the controller loses communication, check the supply directly.

Diagnostics

Controller page unavailable
Check LAN access, nginx, the hp6033a service and its Unix socket. A 502 from nginx points to an upstream connection problem.
GPIB disconnected or readings unavailable
Check supply power and USB/GPIB connections, then inspect the application log. The configured VISA resource is in app.py. The serial probe can respond even when GPIB queries fail.
Interface firmware unavailable
The serial probe opens /dev/ttyACM0 by default at 115200 baud and sends PING and VERSION?. Check the device path, permissions and whether another process has the port open. The service can override the path using HP6033A_ARDUINO_PORT.
Programming rejected
Check the control login, the remote programming state and the actual supply settings. If a command fails during readback, verify the instrument state directly before retrying.

Maintenance and recovery inventory

Application at /home/pi/hp6033a
Keep app.py, templates/, static/, docs/, config.json, scripts/ and the dependency list. Record the working Python and OS versions and the USB device permissions before rebuilding the virtual environment.
Service and web configuration
Preserve /etc/systemd/system/hp6033a.service and the nginx site linked from /etc/nginx/sites-enabled/hp6033a. Record the TLS configuration and back up private keys and both control credential files separately with restricted access.
After a restore
Check the web routes, the service log, GPIB readback and the separate serial probe. Verify programming and output control only during an intentional hardware test. Historical archives are available under the project and in the Pi user's home directory. A full restore from those archives has yet to be verified for this guide.

Web interfaces

GET /api/status
Returns live GPIB measurements, setpoints, output state, saved presets and remote programming state.
GET /api/arduino/status
Returns cached serial diagnostics. Add ?force=1 to request a fresh probe.
POST /api/settings
Updates saved dashboard settings such as the instrument name and preset lists.
POST /api/control/…
Authenticated endpoints for enable, disable, set and output-off. The deployed nginx configuration restricts access to the local network and loopback.
