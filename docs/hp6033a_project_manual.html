Project overview

Goal: Control the HP 6033A DC power supply from a responsive HTML dashboard on a phone or PC over local Wi-Fi, with editable voltage/current presets, measurement readback, scripting, and logging.

Architecture (planned): Phone/PC → Wi-Fi → Raspberry Pi Zero 2 W → USB → ATmega32U4 GPIB controller → IEEE-488 cable → HP 6033A.

Safety: The dashboard and instrument commands are not yet implemented. The HP 6033A is rated 0–20 V, 0–30 A, 200 W; output settings must respect all limits. Never assume software output-off is a physical emergency disconnect.

Initial system commands

Run commands in an SSH session on the Pi. Each block includes a copy button.

Connect from Windows

ssh pi@hp6033a.local

Confirm system and IP

hostnamectl
ip -4 addr show wlan0

Expected: hostname hp6033a, Debian 13 arm64, and a wlan0 IPv4 address.

Install packages and create Python environment

sudo apt update
sudo apt install -y python3-venv python3-pip nginx
sudo mkdir -p /opt/hp6033a
sudo chown pi:pi /opt/hp6033a
python3 -m venv /opt/hp6033a/venv
/opt/hp6033a/venv/bin/pip install flask gunicorn pyvisa pyusb

Dashboard requirements

Dark instrument-style UI, actual voltage/current/wattage readback, independent editable voltage/current presets, manual sliders and fine adjustments, deliberate output on/off control, CV/CC indicators, logging, test scripts, simulation mode, and documentation link.

Safety design requirement: preset selection must not automatically energize the output. Add conservative startup state, input validation, power-limit enforcement, and explicit error indication on communication loss.

Documentation installation

Copy this file to /opt/hp6033a/docs/index.html. Once the Flask app is built, configure a /docs/ route or an Nginx alias to serve this file. Do not assume the URL works until that route is configured.

Create docs directory

Check installed manual
