System architecture

Browser → nginx over HTTPS → Gunicorn on /run/hp6033a/gunicorn.sock → Flask app.py → PyVISA with the @py backend → USB-to-GPIB adapter → HP 6033A.

The Pi Zero 2 W runs the application from /home/pi/hp6033a. systemd runs one Gunicorn worker as pi:www-data. The worker serializes instrument access and holds remote programming authorization in memory. config.json holds dashboard settings and presets. Layout preferences on the Modern dashboard live in the browser.

The app addresses the instrument as a USB VISA resource. A separate optional serial diagnostic uses a USB CDC device, usually /dev/ttyACM0, at 115200 baud. The USB instrument can work without that serial device.

Modern dashboard

  • Readings and status. Read measured voltage, current, calculated power, GPIB connection state, output state, and programmed setpoints. The page polls about every two seconds. A disconnected instrument can leave fallback zero readings. Check the connection indicator first.
  • Interface status. Refresh Status requests a fresh serial diagnostic when supported by the attached firmware. Use the GPIB connection indicator separately to judge instrument communication.
  • Presets and adjustments. Edit saved voltage and current presets in read-only mode. Selecting a preset turns it green immediately and stages the value. Use APPLY SETTINGS in either preset card or under Manual settings to program all staged values and see the verified readback. The preset buttons remain available when the Manual settings card is hidden. RESET discards staged values and restores the highlights to the programmed settings.
  • History. The graph displays recent measured voltage and current from browser polling. Clear graph resets the displayed history.
  • Layout. Customize Layout exposes card arrangement, visibility and sizing options. Save Layout retains the layout for that browser. Reset Layout clears those preferences. Show All Windows makes hidden cards visible.
  • Remote programming. Use the control login to enable programming. The dedicated Output OFF action can be used with programming disabled. A verified shutdown preserves the current authorization state.
  • Front-panel lockout. The page shows a lockout area. The deployed status API reports lockout as not applied and rejects lockout writes through dashboard settings.

Classic Dual View

Open /classic-dual for the instrument-style panel. Display Settings switches between measured values and programmed settings. Select voltage or current, adjust with the knob or step buttons, then use APPLY to send the staged setting. A successful Apply shows the verified setpoints in the confirmation message. The large meters default to measured voltage and current. Display Settings temporarily shows programmed values, and a verified Output ON returns the meters to measured output. Use the OUTPUT status indicator to check whether the physical output is on.

The Classic view polls about every 1.5 seconds. Select a voltage or current preset to stage it and turn its button green. Press APPLY to program the supply or RESET to discard the draft. Save Presets stores edited values and Reload Presets fetches saved values. You can enable or disable remote programming from either dashboard. The physical LINE switch, LCL, OVP, and foldback controls are display-only or disabled in the deployed interface.

Authentication and access

Nginx allows HTTPS from loopback and the configured LAN. For control requests, it compares the browser Origin to the HTTPS host used by the request. The permitted browser address is therefore based on the request host, rather than a hard-coded Wi-Fi address. In dashboard-managed mode Flask checks the controller login against its local bcrypt credential when protection is required.

Open Setup in Modern or Setup & Extra Controls below the Classic instrument. The controller credentials are required to switch password policy in either direction. The change clears remote programming authorization and leaves the physical output in its current state. Use password-free control only on a trusted LAN without internet exposure.

In Classic Setup, edit the model, name, voltage range, current range, and maximum-power labels. The controller saves them for every browser. These labels are display text. The instrument safety limits are enforced separately.

Status, documentation, and dashboard settings use the LAN access policy. The control login is separate from the SSH login. A trusted HTTPS certificate secures the connection. The eye button in an application login dialog temporarily reveals the password field. Dashboard credentials are kept in memory for the current page, so refreshing or switching dashboards can prompt for the login again. Keep TLS private keys and password files out of public source archives.

Output and safety behavior

In Setup, check Skip control confirmation popups to skip the browser prompts. The preference persists for that browser profile and HTTPS URL. Authentication follows the selected mode and server safety checks still apply. Uncheck the box to restore prompts.

  1. Verify that the physical output is off and that existing setpoints are within 0–20 V and 0–30 A before authorizing remote programming.
  2. With output confirmed off, stage and apply changes. The server reads back each setting after writing it. If a write reports an error, verify the actual instrument state before retrying.
  3. For output on, the server rechecks both setpoints, requires at least 0.001 A, and checks that output is currently off.
  4. The dedicated Output OFF action sends OUT OFF and expects OUT 0 on readback. If shutdown cannot be verified, the controller clears authorization.

The supply is autoranging. The maximum voltage and maximum current are separate setpoint limits. Available simultaneous output depends on the instrument's power envelope.

Disabling remote programming or restarting the service clears programming authorization. Neither action sends an output-off command. If communication is lost, verify the supply at its physical panel.

Troubleshooting

Web page fails or returns 502
Check nginx, the Gunicorn service, and the runtime socket. Use the commands on the Command reference page.
GPIB disconnected or zero readings
Check supply power, USB and GPIB cables, device permissions, and the VISA resource string. Confirm the actual output on the instrument.
Serial firmware unavailable
Confirm a USB CDC device exists and is not in use. The inspected Pi showed USB adapter 03eb:2065 without a ttyACM node.
Control returns 401, 403, or 409
Check the control login, exact HTTPS origin, authorization state, output state, and existing setpoints. Check logs and instrument readback for a 503.
Regulation unknown
The deployed API reports regulation as UNKNOWN. Use the physical panel when CV/CC mode matters.
