Linux and service commands

Run these on the Pi. Start with status and logs. Stop and restart interrupt the web interface.

hostname
uname -m
cat /etc/os-release
ip -4 addr show wlan0
id pi
df -h / /home/pi
systemctl status hp6033a nginx --no-pager
journalctl -u hp6033a -n 80 --no-pager
ls -l /run/hp6033a/gunicorn.sock
sudo systemctl start hp6033a
sudo systemctl stop hp6033a
sudo systemctl restart hp6033a
# After changing a systemd unit or override:
sudo systemctl daemon-reload
sudo systemctl restart hp6033a

The commands here and in Installation and Recovery describe the current deployment. A complete record of historical shell commands was unavailable.

nginx and HTTPS

sudo nginx -t
sudo systemctl reload nginx
sudo journalctl -u nginx -n 50 --no-pager
openssl x509 -in /etc/nginx/ssl/hp6033a.crt   -noout -subject -issuer -dates -ext subjectAltName
# Set this to your controller's IP address or hostname:
CONTROLLER_HOST="hp6033a.local"

# Check the documentation and API endpoints:
curl -fsS "https://${CONTROLLER_HOST}/docs/" -o /dev/null
curl -fsS "https://${CONTROLLER_HOST}/api/status"

Use reload after testing nginx changes. A TLS certificate must match the URL and be trusted by the client before the control login is used.

Enable Setup password controls on an updated controller

sudo bash ~/hp6033a/deploy/set-control-auth.sh dashboard

Run once after updating a previously installed application. The command tests Nginx and restores its previous site configuration if activation fails. Use dashboard Setup afterward.

GPIB and serial diagnostics

lsusb
ls -l /dev/usbtmc* /dev/ttyACM*
cd /home/pi/hp6033a
venv/bin/pyvisa-info
venv/bin/python -c "import pyvisa; print(pyvisa.ResourceManager('@py').list_resources())"

Prefer the running application's GET /api/status for live queries. Avoid parallel instrument sessions during direct diagnostics. The application's queries use LF termination and expect a keyword followed by a finite numeric value.

CommandPurposeEffect
VSET? / ISET?Read programmed voltage / current.Query
VOUT? / IOUT?Read measured voltage / current.Query
OUT? / STS?Read output state / instrument status.Query
VSET value / ISET valueProgram voltage / current. The app formats values to three decimal places.Hardware write
OUT ON / OUT OFFEnable / disable the physical output.Hardware write
PING / VERSION?Serial firmware diagnostics. Expected replies are PONG and a string starting HP6033A-GPIB .Serial queries

This is the command set used by the application. Direct writes bypass its remote-control checks.

Application endpoints

GET /api/status
GPIB measurements, setpoints, mode and connection state.
GET /api/arduino/status
Optional serial firmware health. ?force=1 bypasses the cache.
POST /api/settings
Updates dashboard name, Classic front-panel labels, and saved presets. Hardware settings are rejected.
POST /api/admin/control-auth
In dashboard-managed mode, accepts a JSON boolean password_required with the controller login and matching HTTPS Origin. A mode change clears remote programming authorization.
POST /api/control/enable
Enables programming after instrument checks and requires credentials in protected mode.
POST /api/control/disable
Clears authorization. Output state is unaffected.
POST /api/control/set
Expects a JSON object with key and value. Supported keys are voltage, current and output. Output takes a boolean.
POST /api/control/output-off
Turns off output and verifies readback. A verified shutdown preserves authorization. A failed or unverified shutdown clears it.

Typical failures are 400 for invalid input, 401 for credentials, 403 for access or authorization, 409 for enable-time instrument state, and 503 for communication or readback errors.

Update and maintain

Back up the app and configuration before an update. Stage new files on a spare Pi first. Preserve config.json, the credential files, and TLS material. Changes to Python or dependencies require restarting Gunicorn. Documentation and templates can be verified through the HTTPS pages after publishing.

See backup commands and restore commands for the full sequence.
